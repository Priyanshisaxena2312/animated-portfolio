# ✨ Animated Portfolio — Priyanshi Saxena

A modern, interactive, and animation-rich developer portfolio built to showcase my projects, technical skills, experience, and journey as an **AI & ML Engineer and Developer**.

🌐 **Live Demo:** [animated-portfolio-roan.vercel.app](https://animated-portfolio-roan.vercel.app)

## 🚀 About

This portfolio is designed to present my technical background, projects, and achievements through a modern UI, smooth animations, and an engaging browsing experience.

It combines clean design with interactive elements to create a portfolio that reflects my interest in software development, artificial intelligence, and modern web technologies.

## ✨ Features

- 🎨 Modern, visually appealing UI
- 🎬 Smooth animations and transitions
- 📱 Responsive design for different screen sizes
- 💼 Interactive project showcase
- 🧑‍💻 Skills and technology overview
- 🌐 Live project links
- ⚡ Optimized frontend experience
- 🎭 Motion-based UI interactions

## 🛠️ Tech Stack

- **React.js** – Component-based UI
- **JavaScript** – Core functionality
- **Framer Motion** – Animations and transitions
- **CSS** – Styling and responsive layouts
- **React Icons / Lucide** – Icons
- **React i18next** – Internationalization
- **Vercel** – Deployment

## ⚙️ Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/Priyanshisaxena2312/animated-portfolio.git
```

### 2. Navigate to the project

```bash
cd animated-portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the application

```bash
npm start
```

The application will run locally at:

```text
http://localhost:3000
```
